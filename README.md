# Kampüs Etkinlikleri - Sprint 1

Bu proje, kampüs içerisindeki etkinliklerin takip edilmesini ve yeni etkinlikler planlanmasını sağlayan web uygulamasının ilk sprint (prototip) aşamasıdır. Tasarımda CSS veya JavaScript kullanılmamış olup, tamamen semantik HTML etiketleri ve tarayıcı varsayılan stilleri ile oluşturulmuştur.

## 🚀 Canlı Ön İzleme
**Vercel Adresi:** [https://web-design-seven-tau.vercel.app/]

## 📁 Sayfa Yapısı
Proje, ortak bir iskelet (header, nav, main, footer) kullanan 5 temel HTML sayfasından oluşmaktadır:
* `index.html`: Ana sayfa ve yaklaşan etkinlikler özeti.
* `etkinlikler.html`: Tüm etkinliklerin ve ayın programının listelendiği sayfa.
* `etkinlik-detay.html`: Tekil bir etkinliğin afiş, künye ve detay bilgilerini içeren sayfa.
* `etkinlik-ekle.html`: Yeni etkinlik oluşturmak için kullanılan form sayfası.
* `etkinlik-guncelle.html`: Mevcut bir etkinliği düzenlemek için kullanılan, önceden doldurulmuş form sayfası.
